# История изменений

## В разработке (ветка dev)
- Отдельное поле «Исполнитель»: показывается на карточке, странице песни и в плеере, по нему работают поиск и сортировка. Из имени файла вида «Исполнитель - Название.mp3» поля заполняются сами.
- Новый атрибут можно создать прямо в форме песни — его поле сразу появляется в форме, введённое не теряется.
- Дубликаты проверяются до копирования файла: сначала окно «Похоже, эта песня уже есть» с найденными песнями, форма открывается, только если выбрать «Всё равно добавить».
- У уведомлений появился крестик.
- Многострочные атрибуты больше не ограничены 1500 символами (подходят, например, для полного текста песни), поле растёт по мере ввода.
- Исправлено: кнопки в окне «Трек ещё не сохранён» стояли криво — теперь ровным столбиком.
- Исправлено: новый атрибут типа «Число» незаметно получал границы 1–10.

## 1.4.0
- Ссылка на клип: в карточке песни можно указать ссылку на YouTube или любой другой сайт. На странице песни появляется кнопка «Смотреть клип», на карточке — значок-ссылка; ссылка открывается в браузере. Ссылки без «https://» дополняются сами, неправильные не сохраняются.
- Ограничения длины полей со счётчиком символов: название — 120, комментарий и многострочные поля — 1500, короткий текст — 120, названия атрибутов, вариантов и категорий — 40, ссылка — 500. Лишние пробелы и служебные символы убираются при сохранении, в числовых полях проверяется, что введено число.
- Исправлено: в форме песни кнопка «Послушать» не менялась на «Пауза».
- Для разработчиков: AGENTS.md — краткая карта проекта для ИИ-ассистентов.

## 1.3.0
- Длинная строка категорий прокручивается: стрелки по краям и колёсико мыши, выбранная позиция не сбрасывается.
- Своя палитра цветов для категорий и вариантов списков: готовые цвета, свободный выбор и код цвета. У каждого варианта теперь сохраняется свой цвет.
- Порядок атрибутов, категорий и вариантов меняется перетаскиванием за ручку с точками (или стрелками ↑ ↓ с клавиатуры).
- Текст на цветных метках сам становится тёмным или светлым, чтобы всегда читаться.

## 1.2.0
- Кнопка «Хранилище» стала «Настройками»: резервные копии, корзина, перенос библиотеки и повторное обучение собраны в одном месте.
- Новый раздел «О приложении»: версия, что нового, ссылка на проект и контакт автора (Telegram [@arsipa](https://t.me/arsipa)).
- Кнопка «+» в конце строки категорий на главном экране — создать категорию, не уходя к верхней панели.
- Кнопка «Обучение» убрана с главного экрана (теперь в «Настройки» → «О приложении»).

## 1.1.0
- Стартовый экран помещается на экран ноутбука, окно подстраивается под размер экрана.
- Интерактивное обучение при первом запуске.
- Автоматические резервные копии выключены по умолчанию; можно выбрать частоту: день, неделя, месяц.
- Стилизованные выпадающие списки вместо системных.
- Установщик сам удаляет предыдущую версию, данные пользователя сохраняются.
